# 48Kテニススクール — スクール管理システム

テニススクール（一般・ジュニア）向けの管理システム。会員・クラス在籍・欠席連絡・振替・月謝・LINE公式アカウントでの顧客対応・大会運営・売上・スタッフ管理。

## 機能
| 区分 | 内容 |
|---|---|
| 認証 | ログイン／ログアウト、パスワード変更（`/password`）、メールによるパスワード再設定（1時間有効・使い捨てトークン）、5回失敗で15分ロック、初回ログイン時のPW変更強制、PW変更時に他端末セッション失効 |
| 権限 | オーナー / 管理者 / スタッフ の3ロール。マスタ・スタッフ・操作ログは管理者以上、施設設定はオーナーのみ |
| ダッシュボード | 本日の予約数・稼働率・売上・会員数・新規入会、本日のスケジュール |
| スケジュール | 週表示、コート絞込、枠作成（プログラム既定値・毎週繰り返し・コート重複チェック）、編集、中止（予約一括キャンセル＋チケット返却）、削除 |
| 予約 | 会員検索して予約、定員・二重予約チェック（行ロックで同時予約にも安全）、チケット自動消費（月額会員は消費なし）、出席/欠席/取消、キャンセル期限内のみ返却 |
| コース・時間割（48K萩校） | 目的別コース（エンジョイ／アカデミー）× 対象（ジュニア／成人）、アカデミーの段階（スタンダード・アドバンス・プレーヤー・トーナメント）。週の時間割表示（ホームページの時間割と同じ色分け）。「まとめて登録」で萩校の23クラス・受講プラン（月4回・月8回・フリー）・振替ルール・クール制を一括設定 |
| 受講プラン | 月8回＝週2クラスで1プランの月謝、ジュニアエンジョイは2クラス目から2,200円引き、フリーコースは月の上限回数まで登録クラス以下の回を会員が予約（ジュニアのプレーヤーフリーは中学生以上なら成人プレーヤーにも参加可） |
| 出欠 | 日ごとの出欠表（全員出席・出席／欠席をワンタップ、配慮事項の表示）、クラスごとのクール出欠表（○×・欠席連絡・振替・フリー、出席率） |
| クール制 | 3か月1クール（12回）。回の作成は次のクール単位、退会の既定日はクールの終わり |
| スクール | 定期クラス（曜日・時刻・レベル・コーチ・定員）、在籍管理（開始日／最終日）、回の一括生成（在籍者の出席予定を自動作成）、休講（在籍者へ振替を自動発行）、出欠 |
| 在籍管理 | 会員ごとにクラス追加（入会・掛け持ち）、クラス変更（変更日で切替）、クラス単位の退会・スクール退会、月単位の休会（期間中の出席予定を外す）。在籍台帳で月ごとの在籍者と異動（入会・変更・退会・休会）を確認 |
| 月謝 | クラスに月謝（月額プラン）を設定し、在籍から月ごとの請求を作成。月途中の入会・退会・変更はレッスン回数で按分、入会金・休会費に対応。入金済みにすると売上に記録、まとめて入金済み（口座振替の反映）、CSV出力。会員ページに月謝を表示 |
| ジュニア・家族 | クラスを「一般／ジュニア」に区分（振替は同じ区分内のみ）。ジュニア会員に保護者をひも付け、保護者のLINE・会員ページから子どもの欠席連絡・振替予約。お知らせは保護者のLINEへ。保護者が会員ページからお子さまを登録。学年（小3・中1など）を表示 |
| 月謝の集金 | 会員ごとに払い方（口座振替・現金・振込）を設定。口座振替は全銀協フォーマットの依頼データ（山口銀行など、120バイト・半角カナ）を作成し、銀行の結果データを取り込むと振替済は入金済み、振替不能は「引落不能」になり本人（保護者）にLINEで連絡。現金の集金も同じ画面で記録 |
| ガット張替 | 受付（前回と同じ内容で受付）→ 仕上がり（LINEで連絡）→ お渡し・料金（売上に記録）。会員ごとの履歴 |
| 協会・外部の大会 | 協会主催の大会を登録し、会員（保護者は子どもの分も）が会員ページから申込み。窓口での追加、参加費の受領、協会提出用CSV（登録番号・生年月日付き） |
| 顧客データ | 協会の登録番号、緊急連絡先、配慮すること（持病・アレルギー。クラス名簿・出欠に「配慮あり」）、スポーツ安全保険の加入年度、学校名、口座振替の口座 |
| 欠席・振替 | 会員がマイページから欠席連絡→振替1回分を発行。有効期限（既定60日）とレベル条件（同じ／同じか下／制限なし）内で空きのある回に振替予約。振替の取消で権利が戻る、欠席連絡の取消も可。スタッフは手動発行・期限変更・無効化 |
| LINE受信箱 | 公式LINEのトークを管理画面に集約。会員はトーク画面のボタン（欠席連絡・振替予約・予定確認）で自分で手続きでき、自由文は「要対応」としてスタッフが返信。予約確定・欠席受付・休講などの通知も会話に記録。LINEの相手と会員のひも付け、スタッフによる代理の欠席受付・振替予約 |
| 会員 | 一覧・検索・絞込・ページング、登録／編集、チケット手動調整、予約・入金履歴、CSV出力（Excel対応BOM付き） |
| 売上・入金 | 期間集計・支払方法別集計、入金登録（回数券ならチケット付与、月額プランなら会員プラン更新）、返金（マイナス金額）、削除（管理者） |
| マスタ | プラン（月額/回数券/都度）、プログラム（レッスン/貸切/イベントの雛形）、コート |
| スタッフ | 追加（仮パスワード発行）、権限変更、無効化、仮パスワード再発行、強制ログアウト |
| 操作ログ | ログイン・各種変更をIP付きで記録 |
| 施設設定 | 施設名、営業時間、キャンセル期限、ログイン有効時間 |

## 技術構成
Next.js 15 (App Router / Server Actions) + TypeScript + PostgreSQL + Prisma + Tailwind CSS。
パスワードは bcrypt、セッションは DB 管理（Cookie には乱数トークン、DB には SHA-256 のみ保存）。

## セットアップ
```bash
cp .env.example .env          # DATABASE_URL などを設定
npm install
npx prisma migrate deploy
SEED_DEMO=1 npm run db:seed   # デモデータ込み（本番は SEED_DEMO なし）
npm run dev
```
初期オーナー: `owner@example.com` / `ChangeMe123`（`SEED_OWNER_EMAIL` / `SEED_OWNER_PASSWORD` で変更可。デモなしの場合は初回ログイン時に変更を求められます）

メール送信は `SMTP_URL` を設定すると有効になります。未設定時はサーバーのコンソールに本文（再設定URL）が出力されます。
本番では `APP_URL` を公開URLに設定し、HTTPS で運用してください。

## 無料公開（Vercel Hobby + Neon Free）
1. Vercel で本リポジトリを Import（Project Name: `pickleland` → `https://pickleland.vercel.app`）して Deploy
2. プロジェクトの **Storage** → **Create Database** → **Neon**（Free）→ 作成して接続（`DATABASE_URL` などが自動設定されます）
3. **Deployments** → 最新のデプロイの「…」→ **Redeploy**（ビルド時にDBのテーブルが自動作成されます）
4. `https://pickleland.vercel.app/setup` を開いて最初のオーナーを登録（スタッフが0人の間だけ表示）

- 公開URLは Vercel の本番ドメインが自動で使われます（独自ドメインにする場合は `APP_URL` を設定）
- パスワード再設定メールを送るには `SMTP_URL` / `MAIL_FROM` を設定（未設定時は Vercel のログに出力）

## LINE公式アカウントの連携（受信箱・トークでの欠席連絡／振替）
1. LINE Developers で公式アカウントの **Messaging API チャネル**を開き、チャネルアクセストークン（長期）を `LINE_MESSAGING_TOKEN`、チャネルシークレットを `LINE_MESSAGING_SECRET` に設定
2. 同じチャネルの **Webhook URL** に `https://<公開URL>/api/line/webhook` を設定し、「Webhookの利用」をオン（「検証」で成功を確認）
3. LINE Official Account Manager → 応答設定で **Webhook をオン**。チャットは併用できますが、返信は管理画面の「LINE受信箱」から行うと履歴が一か所にまとまります。自動応答メッセージはオフ推奨
4. **リッチメニュー**を作り、ボタンのアクションを「テキスト」にして `欠席連絡` / `振替予約` / `予定確認` / `メニュー` を送るよう設定（これらの言葉は自動で処理されます）
5. 会員ログイン用の **LINEログインチャネルは公式アカウントと同じプロバイダー**に作成（同じ人のLINEユーザーIDが一致し、自動でつながります）。既存の友だちは、受信箱の「会員とつなぐ」で手動でもつなげます

## 2つの別々のシステム（48Kテニススクール／pickleland）
同じコードを、Vercel のプロジェクト・データベースを分けて別々のシステムとして動かします。

| | 48Kテニススクール | pickleland |
|---|---|---|
| Vercel プロジェクト | `48k-tennis` | `pickleland` |
| 機能 | スクール専用（クラス・時間割・在籍・出欠・振替・月謝・口座振替・ジュニア・ガット張替・協会大会・LINE受信箱） | コート施設・大会イベント |

どちらのシステムかは、Vercel のプロジェクト名（URL に「48k」「tennis」が含まれるか）で自動で決まり、本番・プレビューのどちらでも同じです。環境変数 `NEXT_PUBLIC_SPORT=tennis`／`NEXT_PUBLIC_BRAND_NAME` を設定した場合はそちらが優先されます（`NEXT_PUBLIC_SCHOOL=1/0` でスクール機能だけ切り替えも可）。
## 口座振替（山口銀行など）の始め方
1. 銀行と口座振替（預金口座振替）の契約をし、**委託者コード（10桁）** などの通知を受ける
2. 施設設定の「口座振替」に、委託者コード・委託者名（カナ）・取引支店・入金口座・引落日を入力
3. 会員ごとに「払い方：口座振替」と、口座振替依頼書の口座情報（預金者名はカナ）を入力
4. 毎月：月謝の画面で請求を作成 →「依頼データをダウンロード」→ 銀行に送る →（引落日後）銀行の「結果データを取り込む」
- データは全銀協の標準フォーマットです。**最初の1回は銀行にテスト送信して、形式（改行の有無など）が受け付けられるか確認してください**
