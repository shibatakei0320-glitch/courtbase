# CourtBase — コート施設 管理システム

ピックルボール等のコート施設向け管理画面（会員・予約・レッスン・売上・スタッフ管理）。

## 機能
| 区分 | 内容 |
|---|---|
| 認証 | ログイン／ログアウト、パスワード変更（`/password`）、メールによるパスワード再設定（1時間有効・使い捨てトークン）、5回失敗で15分ロック、初回ログイン時のPW変更強制、PW変更時に他端末セッション失効 |
| 権限 | オーナー / 管理者 / スタッフ の3ロール。マスタ・スタッフ・操作ログは管理者以上、施設設定はオーナーのみ |
| ダッシュボード | 本日の予約数・稼働率・売上・会員数・新規入会、本日のスケジュール |
| スケジュール | 週表示、コート絞込、枠作成（プログラム既定値・毎週繰り返し・コート重複チェック）、編集、中止（予約一括キャンセル＋チケット返却）、削除 |
| 予約 | 会員検索して予約、定員・二重予約チェック（行ロックで同時予約にも安全）、チケット自動消費（月額会員は消費なし）、出席/欠席/取消、キャンセル期限内のみ返却 |
| 会員 | 一覧・検索・絞込・ページング、登録／編集、チケット手動調整、予約・入金履歴、CSV出力（Excel対応BOM付き） |
| 売上・入金 | 期間集計・支払方法別集計、入金登録（回数券ならチケット付与、月額プランなら会員プラン更新）、返金（マイナス金額）、削除（管理者） |
| マスタ | プラン（月額/回数券/都度）、プログラム（レッスン/貸切/イベントの雛形）、コート |
| スタッフ | 追加（仮パスワード発行）、権限変更、無効化、仮パスワード再発行、強制ログアウト |
| 操作ログ | ログイン・各種変更をIP付きで記録 |
| 施設設定 | 施設名、営業時間、キャンセル期限、ログイン有効時間 |

## 技術構成
Next.js 15 (App Router / Server Actions) + TypeScript + PostgreSQL + Prisma + Tailwind CSS。
パスワードは bcrypt、セッションは DB 管理（Cookie には乱数トークン、DB には SHA-256 のみ保存）。

## セットアップ
```bash
cp .env.example .env          # DATABASE_URL などを設定
npm install
npx prisma migrate deploy
SEED_DEMO=1 npm run db:seed   # デモデータ込み（本番は SEED_DEMO なし）
npm run dev
```
初期オーナー: `owner@example.com` / `ChangeMe123`（`SEED_OWNER_EMAIL` / `SEED_OWNER_PASSWORD` で変更可。デモなしの場合は初回ログイン時に変更を求められます）

メール送信は `SMTP_URL` を設定すると有効になります。未設定時はサーバーのコンソールに本文（再設定URL）が出力されます。
本番では `APP_URL` を公開URLに設定し、HTTPS で運用してください。
